---
name: code-review
description: Structured checklist for reviewing diffs and pull requests.
---

Follow this checklist when asked to review code:

1. Read the relevant files and diffs to understand scope.
2. List correctness issues first; include reproduction steps if possible.
3. Note performance, security, and reliability risks with actionable fixes.
4. Confirm tests/builds that should run; call them out if missing.
5. Suggest concise improvements; avoid nitpicks unless they affect clarity.
6. Summarize overall confidence and blocking items.
